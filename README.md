# Mesto

Проект "Место" — интерактивная страница, куда можно добавлять фотографии, удалять их и ставить лайки.

## Ссылка на проект

https://zarinamiu.github.io/mesto-production/

## Технологии

- HTML5, CSS3, JavaScript (ES6+)
- Vite
- GitHub Actions

## Запуск проекта

```bash
npm install
npm run dev
